# 市场情绪周期判断器 V2（实盘版）

> 一句话复盘工具：给定交易日 → 输出 **情绪周期阶段 + 最强主线 + 龙头梯队 + 中军名单**

## 功能
1. **情绪周期判断**：6 维打分（涨停/跌停比、连板高度、涨跌比、封板坚决度、封板成功率、赚钱效应）→ 映射到 6 个阶段（冰点/退潮/分歧/发酵/高潮/低位震荡）
2. **主线识别**：统计概念板块涨停家数 + 板块涨跌幅 → 综合得分排序，输出绝对主线 / 次主线
3. **龙头梯队**：主线内按连板数 + 封单强度排序
4. **中军名单**：流通市值 100~800 亿的大票涨停股

## 数据源
- 东方财富（via [akshare](https://github.com/akfamily/akshare)）
- 接口：`stock_zt_pool_em` / `stock_zt_pool_previous_em` / `stock_board_concept_name_em`

## 安装
```bash
pip install akshare pandas numpy
```

## 使用
```bash
# 默认 = 最近交易日（需联网）
python market_sentiment_cycle_v2.py

# 指定日期
python market_sentiment_cycle_v2.py 20260813

# 离线演示模式（无网络 / 沙盒环境）
python market_sentiment_cycle_v2.py --offline
```

## 已知限制
- akshare 涨停池接口仅保留近 ~15 天数据
- 概念板块"领涨股票"可能与涨停池不完全重合（个别龙头属多概念）
- 沙盒 / 无网络环境需使用 `--offline` 演示模式
